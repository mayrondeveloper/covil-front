# Feature: Categorias da premiação

## What
Cadastro e listagem das categorias de uma edição do prêmio (ex.: "Melhor Jogo do Ano", "Melhor Arte"). Cada categoria pertence a uma edição específica e é usada para agrupar indicados e votos.

## Why
A premiação é organizada por categorias. Ter cadastro independente permite reutilizar nomes padronizados entre edições e preparar a estrutura antes de receber votos.

## Acceptance Criteria
- [x] Criar nova categoria associada a uma edição
- [x] Listar categorias existentes
- [x] Excluir categoria
- [x] Consultar categorias por edição do prêmio
